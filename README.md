# 초과근무 월 집계

초과근무 승인 및 월별 집계 Excel 파일을 처리하는 Python 커맨드라인 유틸리티입니다.

## 주요 기능

- `.xls` 형식의 초과근무 승인 파일을 `.xlsx`로 변환
- 초과근무 내역을 기반으로 매식비 검토 파일 생성
- 매식비 대상 항목 제거
- 직원별 초과근무 건수 집계 및 매식비 통계 생성
- 지정된 직원에 대한 공식 데이터 요약 생성

## 요구사항

- Python 3.12 이상
- uv 패키지 관리자
- `pyproject.toml`에 정의된 의존성

## 설치 방법

1. `uv sync`을 실행하여 가상환경을 생성하고 의존성을 설치합니다.

```bash
uv sync
```

## 환경설정

설정 값은 프로젝트 루트의 `config.json` 파일에 저장됩니다. GUI에서 값을
입력하고 "종료" 버튼을 누르면 해당 파일에 자동으로 저장되며, 이후 실행
시 기본값으로 사용됩니다.

## 사용 방법

스크립트를 실행할 때는 `uv run`을 사용해 주세요:

```bash
uv run src/main.py
```

실행 순서는 다음과 같습니다:

1. 최신 `초과근무승인(.xls)` 파일 검색 및 변환
2. 식대 검토 파일 생성
3. 초과근무 건수 집계 및 월별 요약 생성
4. 최신 `초과근무월집계(.xls)` 파일 검색 및 변환
5. 지정 직원에 대한 공식 데이터 생성

## GUI 사용

CLI 대신 간단한 그래픽 인터페이스로도 실행할 수 있습니다. 다음과 같이
실행하면 필요한 설정 값을 화면에서 입력하고 처리를 진행할 수 있습니다.

```bash
uv run src/gui_app.py
```

필요한 경로와 옵션을 입력한 뒤 `실행` 버튼을 누르면 CLI 버전과 같은 절차가
수행됩니다.

## 테스트 실행

프로젝트에는 `pytest`를 사용한 간단한 테스트가 포함되어 있습니다. 다음 명령으로 테스트를 실행할 수 있습니다.

```bash
PYTHONPATH=src pytest
```

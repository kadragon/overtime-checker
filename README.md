# 초과근무 월 집계

초과근무 승인 및 월별 집계 Excel 파일을 처리하는 Python 커맨드라인 유틸리티입니다.

## 주요 기능

- `.xls` 형식의 초과근무 승인 파일을 `.xlsx`로 변환
- 초과근무 내역을 기반으로 매식비 검토 파일 생성
- 매식비 대상 항목 제거
- 직원별 초과근무 건수 집계 및 매식비 통계 생성
- 지정된 직원에 대한 공식 데이터 요약 생성

## 요구사항

- Python 3.12 이상
- uv 패키지 관리자
- `pyproject.toml`에 정의된 의존성

## 설치 방법

1. `uv sync`을 실행하여 가상환경을 생성하고 의존성을 설치합니다.

```bash
uv sync
```

## 환경설정

환경 변수로 디렉토리 경로 및 옵션을 설정합니다. 프로젝트 루트에 `.env` 파일을 생성하거나 쉘에서 직접 변수 설정이 가능합니다.

```dotenv
# 다운로드된 Excel 파일이 저장된 디렉토리
DOWNLOAD_DIR=/path/to/your/downloads

# 처리 결과 파일을 저장할 작업 디렉토리 (월별 폴더로 관리)
WORK_DIR=/path/to/your/workdir

# (선택) 1인당 식대 비용 (기본값: 5500)
MEAL_FEE=5500

# (선택) 공식 데이터 출력 대상 이름(쉼표 구분)
OFFICIAL_DATA_NAMES_STR=이름1,이름2,이름3
```

`.env` 파일은 스크립트 실행 시 자동으로 로드됩니다.

## 사용 방법

스크립트를 실행할 때는 `uv run`을 사용해 주세요:

```bash
uv run src/main.py
```

실행 순서는 다음과 같습니다:

1. 최신 `초과근무승인(.xls)` 파일 검색 및 변환
2. 식대 검토 파일 생성
3. 초과근무 건수 집계 및 월별 요약 생성
4. 최신 `초과근무월집계(.xls)` 파일 검색 및 변환
5. 지정 직원에 대한 공식 데이터 생성

## GUI 사용

CLI 대신 간단한 그래픽 인터페이스로도 실행할 수 있습니다. 다음과 같이
실행하면 환경 변수를 화면에서 입력하고 처리를 진행할 수 있습니다.

```bash
uv run src/gui_app.py
```

필요한 경로와 옵션을 입력한 뒤 `실행` 버튼을 누르면 CLI 버전과 같은 절차가
수행됩니다.

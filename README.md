# 초과근무 월 집계

초과근무 승인 및 월별 집계 Excel 파일을 처리하는 Python 터미널 유틸리티입니다.

## 주요 기능

- `.xls` 형식의 초과근무 승인 파일을 `.xlsx`로 변환
- 초과근무 내역을 기반으로 매식비 검토 파일 생성
- 매식비 대상 항목 제거
- 직원별 초과근무 건수 집계 및 매식비 통계 생성
- 지정된 직원에 대한 공식 데이터 요약 생성
- Rich 라이브러리를 활용한 직관적인 터미널 UI

## 요구사항

- Python 3.12 이상
- uv 패키지 관리자
- `pyproject.toml`에 정의된 의존성

## 설치 방법

1. `uv sync`을 실행하여 가상환경을 생성하고 의존성을 설치합니다.

```bash
uv sync
```

## 환경설정

설정 값은 프로젝트 루트의 `config.json` 파일에 저장됩니다. 앱 실행 시 이전에
저장된 값이 기본값으로 제시되며, 원하는 경우 설정을 저장하여 다음 실행 시
재사용할 수 있습니다.

## 사용 방법

대화형 터미널 인터페이스를 통해 실행합니다:

```bash
uv run src/app.py
```

실행하면 다음 항목을 순차적으로 입력받습니다:

- **다운로드 폴더**: 초과근무 승인 및 월집계 `.xls` 파일이 있는 경로
- **작업결과 저장 폴더**: 처리된 파일을 저장할 경로
- **매식비 기준 금액**: 매식비 지급 기준 금액 (기본값: 5500)
- **대상자 이름**: 공문 데이터를 생성할 직원 이름 (쉼표로 구분)

입력 후 설정을 확인하고 처리를 시작합니다.

### 처리 절차

1. 최신 `초과근무승인(.xls)` 파일 검색 및 변환
2. 식대 검토 파일 생성
3. 초과근무 건수 집계 및 월별 요약 생성
4. 최신 `초과근무월집계(.xls)` 파일 검색 및 변환
5. 지정 직원에 대한 공식 데이터 생성

각 단계는 진행 상황 표시와 함께 실시간으로 확인할 수 있습니다.

## 테스트 실행

프로젝트에는 `pytest`를 사용한 간단한 테스트가 포함되어 있습니다. 다음 명령으로 테스트를 실행할 수 있습니다.

```bash
PYTHONPATH=src pytest
```
